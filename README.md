# Sistem Manajemen Perpustakaan Kampus

Program **Sistem Manajemen Perpustakaan Kampus** merupakan tugas Pemrograman Berorientasi Objek yang dibuat menggunakan bahasa pemrograman Java. Program ini menerapkan enam struktur data untuk mengelola buku, lokasi penyimpanan, transaksi peminjaman, dan antrean mahasiswa.

## Fitur Program

- Menampilkan kategori buku.
- Menampilkan statistik peminjaman berdasarkan kategori dan hari.
- Menampilkan, mencari, dan memindahkan lokasi buku.
- Menambahkan, menampilkan, dan menghapus data buku.
- Melakukan peminjaman dan pengembalian buku.
- Menampilkan riwayat transaksi dan membatalkan transaksi tertentu.
- Mengelola antrean mahasiswa berdasarkan urutan kedatangan.
- Memvalidasi input pengguna pada bagian yang telah disediakan.

## Struktur Data yang Digunakan

| Struktur Data | Penerapan |
|---|---|
| Array 1D | Menyimpan kategori buku dan nama hari. |
| Array 2D | Menyimpan statistik peminjaman berdasarkan kategori dan hari. |
| Array 3D | Merepresentasikan lokasi buku berdasarkan lantai, rak, dan posisi. |
| ArrayList | Menyimpan dan mengelola daftar buku secara dinamis. |
| Stack | Menyimpan riwayat transaksi dengan prinsip LIFO (*Last In, First Out*). |
| Queue | Mengatur antrean mahasiswa dengan prinsip FIFO (*First In, First Out*). |
